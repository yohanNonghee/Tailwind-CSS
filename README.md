# Aurum Luxury Gym — Private Performance Gym

A modern, responsive dark-mode landing page for Aurum Luxury Gym, an exclusive performance facility engineered for strength, recovery, and quiet focus.

# 📌 Project Overview
This website serves as the primary digital portal for prospective and existing gym members. It communicates brand luxury through dark slate textures, brushed gold accents, panoramic imagery, and structured access options.

# ✨ Key Features & Sections
- Hero & Access Card: High-impact hero section with primary action buttons and a quick-reference card displaying members-only access hours (05:00 — 23:00).  
- Facility Highlights (#Gym): Showcases flagship spaces such as the Functional & Strength Arena and the high-rise Skyline Deck cardio suite.  
- Atmosphere Gallery (#gallery): Interactive visual grid highlighting specialized areas, including Precision Free Weights, Endurance Zones, Private Suites, and the Recovery Lounge.  
- Performance Training (#training): Detail cards for 1-on-1 Performance coaching, Metabolic Conditioning, and dedicated Recovery Protocols.  
- Membership Plans (#membership): Transparent tier comparison highlighting pricing and key privileges.  
- Tour Request Form (#visit): Interactive booking form capturing client name, email, and primary fitness goal.  
- Footer Navigation: Complete directory containing operating hours, location details, and policy links.  


# 🛠️ Tech Stack & Dependencies

- HTML: Semantic document layout 
- Tailwind CSS: Styled with custom color utilities (bg-obsidian, bg-charcoal, bg-surface, text-steel, border-gold) and smooth-scrolling behavior.  
- Google Fonts: Implements Playfair Display (serif headers) and Inter (sans-serif body text).  
- JavaScript: Event-driven form submission handling via script.js.
